# Mica Maccy

`mica-maccy` 是参考 [Maccy](https://github.com/p0deje/Maccy) 的 macOS 剪贴板管理插件。按 **⇧⌘C** 或点击菜单栏剪贴板图标，随时搜索、预览、复制历史内容。界面使用 Mica 现有的 Arco 共享组件和主题。

## 使用

在 **Settings → Plugins → Mica Maccy** 启用插件。启用后随桌面应用监听剪贴板，不依赖聊天会话，也不需要先打开历史窗口。关闭主窗口时继续记录；停用插件或退出应用时停止监听、移除菜单栏图标并释放快捷键。

- 输入关键词搜索，按全部、固定、文本、图片、文件筛选。
- 图片在列表中显示缩略图与原始尺寸，横图、竖图都按比例完整显示；悬停后右侧展示大图。缩略图按可见范围分批加载，解码失败时保留图标和复制操作。
- 鼠标移到条目上查看全文、图片或文件路径；点一下就是用它：默认复制，⌥ 点击直接回贴。
- 整理动作在条目的右键菜单里：**复制、粘贴、纯文本粘贴、固定、重命名、删除**。粘贴会关闭浮窗，回到原应用执行；纯文本粘贴会去掉富文本格式。
- 固定内容始终排在前面，不计入普通历史上限，也不受自动过期清理影响；取消固定后重新计入。
- 界面上不放成排的按钮。暂停记录在设置或菜单栏图标（按住 Option 点击）切换，暂停时筛选行左侧的「已暂停 · 继续记录」点一下就能恢复。

界面仅突出 ⇧⌘C。辅助键盘操作保留 ↑/↓ 选择、回车执行默认动作、⌥回车粘贴、⌥⇧回车纯文本粘贴、Esc 关闭，以及 Maccy 的数字选择、固定（⌥P）、删除（⌥⌫）、清理（⇧⌥⌘⌫）组合键。

## 记录与搜索

支持纯文本、HTML/RTF 等富文本表示、PNG/TIFF/JPEG 图片，以及 Finder 文件引用；恢复时保留同一条目的多种支持格式和多个文件引用。文件历史保存路径引用，不复制文件本体。

默认保留 **最近 31 天**、最多 **500 条未固定历史**，检查间隔 **500 ms**，单条原始内容上限 **5 MiB**。后台每分钟按「历史保留时间」清理过期条目，索引与内容文件一起删除，不需要手动清空；固定条目不受影响。同一内容只存一份，再次复制会更新时间和次数。可设置按最近复制、首次复制或使用次数排序，或调整保留天数、数量和大小限制。

搜索覆盖完整文本、条目标题和来源应用，提供模糊匹配、包含关键词与正则表达式三种方式。列表只读取摘要，全文与图片预览按需加载；无效正则会显示原因并保留搜索输入。

## 隐私与权限

历史仅保存到本机 `$MICA_HOME/plugin-data/mica-maccy/`。目录权限为 `0700`，历史与内容文件权限为 `0600`；内容以明文保存。插件不调用模型，也不进行云同步。

以下标记在读取正文之前就会被过滤，不能取消：

- `org.nspasteboard.TransientType`
- `org.nspasteboard.ConcealedType`
- `org.nspasteboard.AutoGeneratedType`

默认还忽略 Maccy 使用的 1Password、TypeIt4Me、KeeWeb 等类型。这份附加清单可编辑或清空；还可按应用名称、Bundle ID（支持 `*` 与 `?`）忽略来源，以及忽略 Apple 通用剪贴板。暂停或忽略下一次时，原生组件不会把该次正文发送给插件后端。

复制与记录不需要辅助功能权限；**自动粘贴需要为 Mica Code 授予辅助功能权限**。插件设置的「运行条件」提供系统权限检测与授权入口。缺少权限时内容仍会复制到剪贴板，窗口保留清楚的提示。

权限状态随剪贴板轮询更新，即使没有新复制的内容也会重新检测；授权或撤销后，历史窗口的提示会在下一次列表刷新时同步，无需重启插件。窗口里的「重新检测」也会立即重查原生组件的权限。

原生协议的权限字段统一输出 JSON 布尔值 `true/false`；macOS 的 `AXIsProcessTrusted()` 返回 C `Boolean`，直接装箱会变成数字 `1/0`，使前端严格布尔判断误报缺少权限。

首次启用需要 Xcode Command Line Tools，用于在插件自己的数据目录准备一次原生组件。未安装时按提示执行 `xcode-select --install`，然后点击「重新检测」。原生组件不依赖其它剪贴板软件或 `computer-use` 插件。

## 设置

设置页使用现成的插件设置表单，修改自动保存：

| 设置                               | 默认值                            |
| ---------------------------------- | --------------------------------- |
| 唤出快捷键                         | `CommandOrControl+Shift+C`（⇧⌘C） |
| 未固定历史上限                     | 500 条                            |
| 历史保留时间                       | 31 天，过期自动清理               |
| 搜索方式                           | 模糊匹配                          |
| 历史排序                           | 最近复制                          |
| 选择后自动粘贴                     | 关闭                              |
| 始终去除文本格式                   | 关闭，仅适用于文字                |
| 内容预览 / 底部状态栏 / 菜单栏图标 | 开启                              |
| 暂停记录 / 忽略通用剪贴板          | 关闭                              |
| 单条大小上限                       | 5 MiB                             |
| 检查间隔                           | 500 ms                            |

唤出快捷键修改后即时重新注册；发生冲突时窗口会显示原因，可以从菜单栏或插件详情进入。菜单栏图标按住 Option 点击切换暂停，Option + Shift 点击忽略下一次。

## 实现与验证

- `desktop.jsx` / `desktop.css`：共享组件、列表、预览和交互。
- `model.js`：去重、隐私规则、搜索、固定与淘汰策略。
- `store.js`：带跨进程锁和原子写入的 `history.json`、`clips/<sha256>.json` 与独立小缩略图缓存；损坏索引会拒绝写入并保留原文件。
- `launcher.js`：与聊天无关的启动器后端，使用宿主 `background` 调度；同一数据目录只有一个观察者。
- `native.js` / `native-source.js`：AppKit 剪贴板、菜单栏与回贴；通过 stdin/stdout 通信，父进程退出或输入关闭时终止，停用时显式回收。

只支持 macOS 桌面版的原生监听和回贴。浏览器及其它系统会显示能力限制，不冒充已经在监听。

针对性验证：

```bash
bunx vitest run --project unit plugins/mica-maccy
bun run typecheck
```

界面版式（搜索行、列表 + 预览、右键菜单、暂停胶囊）用真实组件的探针看：

```bash
cd apps/desktop && npx vite --config .probe/maccy/vite.config.mjs   # http://127.0.0.1:5240/?theme=light
```

原生读写使用 `--self-test` 验证独立的临时 pasteboard，不修改用户正在使用的系统剪贴板；同时检查启动、状态与两种轮询路径的权限值确实是布尔类型（`permissionBooleans`），防止模拟响应漏掉原生序列化问题。应用构建与重启按仓库 `agent/build.md` 执行，由用户决定时机。

本插件参考 Maccy 的功能与交互，使用 Mica 的组件和插件机制重新实现；未引入 Maccy 可执行文件或数据格式。Maccy 项目采用 [MIT 许可证](https://github.com/p0deje/Maccy/blob/master/LICENSE)。
