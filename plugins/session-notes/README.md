# Session Notes

会话笔记：一份用户与模型共享的 markdown 文档，存在会话快照里而不是对话历史里。

- 不会被上下文压缩改写，每轮都会重新附到 system prompt 末尾
- 用户可以在桌面端顶栏的笔记卡片里编辑，模型用 `session_notes` 工具读写；入口与编辑器都在
  本插件里（清单 `desktop.entry` + `desktop.jsx`），停用插件就一起消失
- 会话结束、fork、resume 都跟着会话走；rewind 随 checkpoint 一起回滚

## 工具

`session_notes` 有五个动作：

| action            | 作用                                                   |
| ----------------- | ------------------------------------------------------ |
| `read`            | 读当前内容，空时返回提示而不是空字符串                 |
| `append`          | 在末尾追加一段，已有内容保留                           |
| `replace`         | 整篇替换，传空字符串清空笔记                           |
| `replace_section` | 只重写某个标题下的正文，标题与其余章节原样保留         |
| `remove_section`  | 删掉某个标题及其正文（含其下级小节），其余章节原样保留 |

`replace_section` / `remove_section` 是「笔记到上限」时的正确出路：以前只有 `replace`
一条路，模型必须重新生成整份两万字的笔记，既贵又容易顺手丢掉别的章节。`section`
按标题匹配（可以带也可以不带 `#`），必须**唯一**——同名标题时直接报错并给出行号，
猜测要删哪一个比报错更糟。围栏代码块里的 `#` 不算标题。

工具只改内存，落盘交给本轮的 session checkpoint；不要在工具里自己写盘。

## 文件

| 文件                | 职责                                                   |
| ------------------- | ------------------------------------------------------ |
| `index.ts`          | 注册工具与 prompt 段落                                 |
| `desktop.jsx`       | 顶栏入口与编辑卡片（读写会话快照，别的窗口改了就跟上） |
| `NotesTool.ts`      | 工具定义、入参解析、五种动作的实现                     |
| `notesSection.ts`   | 拼进 system prompt 的那段说明                          |
| `NotesTool.test.ts` | 入参与动作的行为测试                                   |
