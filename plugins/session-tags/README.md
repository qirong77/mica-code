# Session Tags

会话标签，形态照 macOS Finder 的彩色圆点：**7 个固定色槽**（red / orange / yellow / green /
blue / purple / gray），每个色槽有一个可改的名字，一个会话可以挂多个。

- 标签是**跨分区的检索维度**，不是第三种归档方式：侧栏的 Pinned / Projects / Recent 仍然
  遵守「一个会话只在一个位置」，标签只挂在会话上，不改归属。
- 颜色固定，不能新增色槽——自由取色在深色侧栏上对比度不可控，要表达新分类就改某个色槽的名字。
- 行内圆点按固定色序排列，不按添加顺序，所以打标之后位置不会跳。

## 命令

| 命令                     | 作用                                  |
| ------------------------ | ------------------------------------- |
| `/tags`                  | 列出 7 个色槽、各自的用量与当前会话的标签 |
| `/tags add <颜色>`       | 给当前会话打标，可跟多个颜色          |
| `/tags remove <颜色>`    | 去标                                  |
| `/tags rename <颜色> <名字>` | 改色槽名字（改完全局生效）         |
| `/tags clear`            | 清空当前会话的标签                    |

`<颜色>` 接受色槽 id（`red`）、默认名（`Red`）或用户改过的名字，大小写不敏感。

## 工具

`session_tags` 只有三个动作，**只作用于当前会话**：

| action   | 作用                                     |
| -------- | ---------------------------------------- |
| `read`   | 当前会话的标签 + 每个色槽的用量          |
| `add`    | 打一个色槽（需要 `color`）               |
| `remove` | 去掉一个色槽（需要 `color`）             |

工具描述里明确写了「只在用户要求时改」：标签是用户的分类习惯，不是模型可以主动整理的元数据。

## 存储

`$MICA_HOME/session-tags.json`：

```json
{
  "version": 1,
  "labels": { "red": "Red", "orange": "Orange", "...": "..." },
  "assignments": { "<sessionId>": ["red", "blue"] }
}
```

- 不能放 `ctx.sessionState`：那是一种会话内的状态，而标签要能跨会话列出来。
- 不能放 `ctx.settings`：插件设置只能存清单里声明过的键、值一律是字符串。
- 文件被手改坏时按「空表」继续跑并上报一次健康状态，不让标签把会话带崩。
- 会话被删掉之后它的 `assignments` 会变成孤儿：读的时候按会话列表 join，孤儿看不见。

## 为什么还没有侧栏圆点

`ctx.ui` 目前只有 `submit` / `showMessage` / `status` / `input`，没有任何「往会话行里塞东西」
的扩展点。要在侧栏画圆点，得由宿主提供一条通用的**插件数据 → 会话行徽标**通道，而不是先
在宿主里写死一个叫 tags 的概念——否则标签的形态（色槽数量、上限、筛选规则）就锁死在核心里，
插件系统也就失去了意义。

## 文件

| 文件              | 职责                                     |
| ----------------- | ---------------------------------------- |
| `index.ts`        | 注册命令、工具与 prompt 段落             |
| `tags.ts`         | 纯数据层：色槽、名字、归属与各种收敛规则 |
| `storeFile.ts`    | `session-tags.json` 的读写与 mtime 缓存  |
| `TagsTool.ts`     | `session_tags` 工具与入参解析            |
| `tagsSection.ts`  | 拼进 system prompt 的那段说明            |
| `tags.test.ts`    | 纯数据层的行为测试                       |
