# Notebook

Mica 里的本地笔记本：采用分区工作台布局，左侧目录树、中间完整 Lexical 编辑器、右侧可收起的大纲。入口是主区顶栏右侧的 **Notebook** 图标（与 **Schedule** 同一排），不依赖聊天会话或工作区目录。

入口使用极简书脊图标（`book-spine`）：圆角封面加一条竖向书脊，无装订线圈与笔；顶栏和插件目录共用图标表，大小与颜色沿用宿主设置。

## 分区工作台

- 目录与正文采用轻量分区，使用 Mica 现有主题、Arco 控件和六套明暗配色；正文限宽排版，表格、代码、图片说明与 Mermaid 使用同一套视觉规则。
- 顶部“最近阅读”显示本次打开页面后成功访问的笔记，最多六篇，切换前仍执行原有保存流程。重命名实时更新页签，移入最近删除的笔记不再显示；阅读记录仅是页面状态，不改写笔记索引。
- 右侧大纲实时读取当前笔记 H1–H6，H2 使用编号，随正文滚动标记当前位置；点击可跳到对应标题。表格内的标题与图片说明不计入文档大纲。
- 内容索引只展示当前文档已有的表格、代码、Mermaid 图表和图片，可直接跳转；导航与专注布局不修改正文、选区或撤销记录。
- 专注写作临时收起目录、大纲、阅读页签和辅助信息；退出后恢复布局。窄屏将目录与大纲按需展开为覆盖面板，为正文留出空间。

## 编辑与保存

- 新建笔记和多层文件夹、标题搜索、重命名、移动、最近删除与恢复。
- 正文约 650ms 自动保存，自动保存、切换与关闭共用串行写入队列；写入期间的新输入会在同一队列里继续保存，失败保留草稿与原版本供重试。写入未确认时，即使撤销回旧正文也保持未保存，只有写入确认或显式加载最新版才恢复可信基线。每篇笔记独立撤销历史、评论和图片说明。
- 切换或重载笔记期间冻结编辑器，收到本次加载的确认后才恢复编辑；失败保留错误界面供重试。同一篇笔记的旧加载回包、正文和大纲不能影响重载后的文档。
- 返回对话前立即进入关闭状态，阻止切换、重载和替换正文；取消尚未应用的在途读取，等待已经开始的编辑器加载结束，再收集正文并保存正文与索引。关闭成功后保持冻结，关闭失败才恢复编辑。
- 保留 Lexical 0.53.0 的常用编辑与表格能力：行列选择、增删、合并拆分、拖动换序、排序、批量样式及数据粘贴，以及图片、代码、公式、绘图、日期与折叠区块。
- 工具栏按历史、段落、字体字号、常用格式及插入分组；窄屏使用两行紧凑布局，必要时可横向滑动。低频文字格式与查看评论收进“更多”，底部只显示字数。
- 粘贴带有明确 Markdown 标记的文本会转换为标题、列表、引用、表格等富文本；保留已有富文本剪贴板格式，在代码块中粘贴则保留源码。
- 移除 Playground 的底部演示操作条、右下角评论悬浮按钮、实验设置及旧大纲入口和投票、示例 GIF 等插入入口；大纲统一放在宿主工作台右侧，不删除既有笔记中这些节点的解析和内容。评论仍可从“更多 → 查看评论”访问。
- 宿主页导出入口可下载当前笔记 JSON；保存冲突时可以下载草稿，并明确确认后载入磁盘最新版，不静默覆盖另一窗口的正文。
- 主页面使用 Mica 共享 Arco 控件。隔离编辑器复用项目 `arco-settings.css` 的同一套主题映射，跟随宿主明暗主题与强调色。

## 本地数据

默认位置：

```text
$MICA_HOME/plugin-data/notebook/
  data.json               # version:1 的文件夹/标题索引，256 KiB 上限
  documents/<uuid>.json   # 每篇正文和评论，6 MiB UTF-8 JSON 上限
```

`MICA_HOME` 默认 `~/.mica`。正文不是浏览器 localStorage，也不依赖旧编辑器项目。图片上传和粘贴按编辑器规则以内嵌内容保存，计入正文上限；网络图片仍是远程引用。重要笔记建议额外导出备份。

写盘复用宿主跨进程锁、内容版本比较、0600 权限、临时文件原子替换。宿主直接返回实际写入内容的版本，正文自动保存不必再传输整篇文档来确认版本。不同笔记互不覆盖；同篇版本冲突保留内存草稿并提示处理。选择「加载最新版」时先收集最后一批输入、等待正在执行的写入结束并下载草稿备份，再读取磁盘最新版。最近删除是索引软删除，不删除正文文件。读取非法/损坏笔记明确报错，不把它当空文档覆盖。

## 运行时依赖

编辑器已抽成共享包 `packages/mica-editor`：笔记用它运行时的富文本模式，配置页 Role / Skill 用同一份运行时的 Markdown 模式（两份文档契约互不相通，见该包 README）。本插件只保留目录模型、保存控制和 iframe 桥。`packages/mica-editor/runtime/cdn.mjs` 固定第三方版本，浏览器通过 esm.sh 加载 ESM、jsDelivr 加载样式与字体；本地产物只包含一方代码、图标和编辑器主题资源，不复制第三方 JS 库。Lexical 导出与 `.js` 别名由 import map 统一，避免编辑器上下文出现两个实例。

编辑器在无 `allow-same-origin` 的 sandbox iframe 中运行，通过 iframe WindowProxy + 随机 nonce 校验的消息桥交换当前笔记正文，不提供 Mica API 或文件系统权限。每次加载另带独立请求身份，超时或被替换的请求不能完成后续加载；编辑器关闭后新请求立即失败。CDN 只负责库文件，不发送笔记正文；网络图片/视频等外部嵌入会请求相应站点。首次打开需要网络；不能承诺完全离线运行，CDN 失败时展示可重试错误且不清空本地笔记。

协同服务、分享快照和会重建文档的 Playground 实验模式不用于本地笔记，不提供语音和 Markdown/HTML 源码模式入口。外部嵌入仍受浏览器能力、iframe 权限和网络约束。

## 开发

共享编辑器的开发依赖不加入 Mica 主运行时依赖：

```sh
cd packages/mica-editor/runtime
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
npm test
```

主仓库类型检查排除这份独立 CDN 运行时，分别检查。宿主用 `packages/mica-editor/build.mjs` 的 `editorWebAssets()` 把隔离页面构建到 `/editor/`：桌面 renderer 输出到 `out/renderer/editor/`，配置 Web 输出到 `apps/config-web/web/dist/editor/`；开发服务首次请求时按需构建到仓库 `temp/editor-web-dev/`。本插件不再有自己的 `web-build.mjs`。

仅测试独立页面资源时（输出放临时目录，不覆盖已安装应用）：

```sh
node --input-type=module -e "import build from './packages/mica-editor/build.mjs'; await build({ outDir: '/private/tmp/mica-editor-assets' })"
```

索引与正文都使用 `version:1`；iframe 的请求身份只属于运行时，不写入笔记内容。编辑器上游代码保留 Meta MIT 版权头，许可证见 `LICENSE.lexical`。
